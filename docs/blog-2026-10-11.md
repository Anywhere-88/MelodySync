# Bro 使用 AI+手打制作的音乐软件：两个月，一个 exe，拳打什么来着？

孩子们，Bro 今天来水一篇帖子，推荐一下我自己作的开源音乐软件 **MelodySync**。

先说结论：**单文件 exe，双击就跑，不用安装 Python、不用配环境变量**。这个软件断断续续做了两个月，AI 写骨架 + 我手打调教，踩的坑比写的代码还多（后面开源了你们可以自己数）。

## 一、AI 全网搜（核心功能）

在搜索框里用人话描述你想听的歌（比如「Jay 的晴天」「Why We Lose NCS」），AI 会解析出歌手/歌名/时长，然后**全网找**：B 站、YouTube、SoundCloud 级联检索，逐条打分排序——歌名相似度、原唱匹配、热度、音质、能不能下载，全都算分。

![AI 搜索](/file/19/blogplus-img-mv32ll4s-v5b07i.png)

几个设计上比较得意的地方：

- **搜到的基本都能下**。搜索和换源用同一套评分口径，官方 MV、原唱优先；翻唱/伴奏/合集/试听版会被三道闸门压下去。
- **每个源什么情况都告诉你**。哪个源超时、哪条结果是「仅试听」、为什么，界面上写得明明白白，不跟你玩玄学。
- AI 模型默认接的是**智谱的免费模型**，想换自己的 API？设置页直接改，provider、baseUrl、模型名都开放。

## 二、歌单解析

把网易云/QQ 歌单链接粘进来，解析出全部曲目，批量导入下载队列。歌单里某首歌全网搜不到？队列会跳过它并标注原因，不会卡死在一首歌上。

## 三、播放

该有的都有：本地媒体库、播放队列、播放器界面。下载完的歌自动进库。

## 四、设备同步

插上 MP3/MP4、手机这类外部设备，软件能识别出来，**直接把下载好的歌同步上去**，不用你再开文件管理器拷来拷去。

## 五、一些不用夸张但很顶的细节

- **单 exe 架构**：Qt WebEngine 界面内嵌进 exe，配 yt-dlp + ffmpeg 两个 sidecar，绿色便携。
- **下载校验**：下完核对字节数、ffprobe 核对时长，下错版本会被判失败重找。
- **换源防错版**：搜索结果与换源候选共用一套评分，时长对不上、歌手对不上都会被扣分或直接放弃（「已放弃以免下错版本」）。
- **自检探针**：一条命令 `MelodySync.exe --probe "歌名"` 就能无界面跑完整搜索下载链路，出问题知道是哪个环节坏了。

```
git clone https://github.com/你的用户名/MelodySync.git
cd MelodySync
python tools\build.py
```

构建脚本全自动：拉依赖、配置、编译一条龙，产物在 `build\bin\MelodySync.exe`。
